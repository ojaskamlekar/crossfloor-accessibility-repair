# The precise supported contribution and its boundary

The claim is a **constructive semantics-preserving transfer of complete physical
action purchases to a recognized owned-cell floor interface**, with exact
rooted repair in `T_rec + 2^O(prL+zL log(h+2))*poly(B)`. This is not a claim
that shared prices, conflict graphs, profile-restricted paths or representative
partitions were invented here. Generic weighted logic and our executed CP-SAT
model can express the whole recognized problem. Broad algorithmic priority
against all domain-valued resource/connectivity DPs remains unconfirmed.

Do not conflate: (E) expressing the instance, (A) an applicable algorithm,
and (P) proving the same dependence on the supplied physical parameters.
This table is a scoped correspondence audit, not an exhaustive absence proof.

## Proposition actually established by the project argument

For every instance admitted by the recognizer, a selected original action set
is feasible in the full physical graph iff it admits an accepting owned-cell,
profile-separated witness execution; the least original cost/count/ID label is
preserved. The recognition, complete-unit locality, thin-witness correspondence,
forgetting and weighted completion arguments are enumerated in
`review2_theory_package.md`. The owner domain gives h(J,c)+2 statuses, producing
the displayed bound. Generic logic expressly covers the instance; the current
comparison establishes a sharper displayed h dependence than **one** transferred
expression, not novelty over every algorithm that can express the problem.

This replaces an undifferentiated novelty question with a falsifiable scope:
the supported scientific result is an exact physical/interface transfer. Whether
that transfer merits a major algorithmic originality claim needs independent
review of the closest domain-valued resource formulation. It is not settled by
these experiments, by having a different application, or by more citations.
